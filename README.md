# Hack The Mainframe (Sort Of)

I made this little project over the weekend because I wanted to practice some basic JS and finally figure out how to center a div properly (shoutout to Flexbox). 



### How to run it:
1. Just open `beest PROJECT.html` in any browser.
2. Type in your guess.
3. If you get it right, you'll see a cool win screen I just added.
4. If you fail 5 times... well, get rekt.

### Things I learned:
- Flexbox is actually magic once you get it.
- `var` is still fine for small stuff.
- Making popups is satisfying.
